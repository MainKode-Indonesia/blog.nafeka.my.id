# Memulai Perjalanan sebagai Web Developer

Web development adalah proses membangun dan mengembangkan website atau aplikasi berbasis web.

Bagi pemula, dunia web development mungkin terlihat rumit. Namun, semuanya bisa dimulai dari memahami tiga teknologi dasar.

## 1. HTML — Struktur Website

HTML adalah bahasa markup yang digunakan untuk menyusun struktur halaman web.

Contohnya:

```html
<h1>Halo, Dunia!</h1>
<p>Ini adalah website pertamaku.</p>
```

## 2. CSS — Tampilan Website

CSS digunakan untuk mengatur warna, ukuran, tata letak, dan tampilan halaman.

```css
h1 {
  color: blue;
  font-size: 32px;
}
```

## 3. JavaScript — Interaktivitas

JavaScript memungkinkan website merespons interaksi pengguna.

```javascript
console.log("Halo dari JavaScript!");
```

## Langkah Selanjutnya

Setelah memahami HTML, CSS, dan JavaScript, kamu bisa mulai mempelajari Git, framework frontend, serta dasar-dasar backend.

Tidak perlu menguasai semuanya sekaligus. Mulailah dengan proyek kecil dan terus kembangkan kemampuanmu.
